# SpongeBob Series

Fan-made Codex desktop pets inspired by classic undersea cartoon characters.
Each pet is generated as a deterministic v2 atlas so animation frames and
look-direction frames keep a consistent identity.

## Pets

- `spongebob` - SpongeBob
- `patrick` - Patrick
- `mr-krabs` - Mr. Krabs
- `plankton` - Plankton
- `squidward` - Squidward

Install the whole series:

```bash
./install.sh spongebob
```
