# One Piece Codex Pets

海贼王角色 Codex 桌宠集合。每个角色都按 Codex 的 9 行状态图集制作，并尽量保留角色的经典外观和动作特色。

## 角色

| 角色 | 路径 | 特色动作 |
| --- | --- | --- |
| Luffy | [`luffy`](./luffy) | 橡胶跑、橡胶跳、橡胶拳、眺望 |
| Chopper | [`chopper`](./chopper) | 小鹿跳、害羞、医生包检查 |

## 安装

从仓库根目录安装全部 One Piece 桌宠：

```bash
./install.sh one-piece
```

只安装一个角色：

```bash
./install.sh one-piece/luffy
./install.sh one-piece/chopper
```
